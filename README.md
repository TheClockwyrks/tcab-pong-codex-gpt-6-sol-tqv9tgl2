# Carom

Carom is a browser paddle duel with curving shots and rotating obstacles. Move your paddle as the ball strikes it to add spin, then bank the return through the middle of the field. Play against the AI or share a keyboard for a local duel. The first player to 11 points with a two point lead wins.

## Run

```sh
npm ci
npm run dev
```

Open the URL Vite prints. For a self-contained static build, run `npm run build` and serve `dist/` at the root of any static file server.

## Controls

| Action | Keys |
| --- | --- |
| Left paddle | W / S |
| Right paddle | Up / Down |
| Menu selection | W / S or Up / Down, then Enter or Space |
| Pause / resume | P or Escape |
| Mute | M |

In Solo, either pair of movement keys controls your paddle. Menus also support mouse and touch. On a touchscreen, the engine shows on-screen movement controls.
